# Formulário de Cadastro Moderno

Um formulário de cadastro responsivo e moderno desenvolvido com HTML, Tailwind CSS e JavaScript puro.

## Características

- Design moderno e minimalista
- Totalmente responsivo
- Validações em tempo real
- Suporte a caracteres especiais no nome
- Validação de e-mail
- Feedback visual para o usuário

## Tecnologias Utilizadas

- HTML5
- Tailwind CSS
- JavaScript (ES6+)

## Funcionalidades

- Validação de nome completo (mínimo 3 caracteres, apenas letras)
- Validação de e-mail
- Validação de mensagem (mínimo 10 caracteres)
- Feedback visual em tempo real
- Mensagens de erro personalizadas

## Como Usar

1. Clone este repositório
2. Abra o arquivo `index.html` em seu navegador
3. Teste o formulário preenchendo os campos

## Estrutura do Projeto

```
├── index.html    # Arquivo principal com o formulário
```
